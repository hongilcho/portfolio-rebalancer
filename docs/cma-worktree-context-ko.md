기존 CMA 개발/실연결 시도 문서는 역사적 결과다. [CMA 준비 개발](cma-interest-development-ko.md), [읽기 전용 및 PostgreSQL 검증](cma-readonly-postgres-validation-ko.md), `cma-source-context-before-split-ko.md`의 이전 원래 경로/브랜치 설명보다 이 문서를 우선한다. 실제 응답·승인 경계는 아래와 같다.

- 저녁 전환의 정확한 시각은 모른다. **20시 확정이 아니다.** 예수금이 0원이어도 MTS 출금가능금액은 전체 잔액을 표시한다고 사용자가 정정했다. 2026-10-15에 준비 코드의 20시 차단을 제거했다. 기존 `dca`/CMA 상품 평가액과 `drn_pbl_amt` 참고값을 분리했으며 실제 응답의 필드 의미 검증은 아직 필요하다.
