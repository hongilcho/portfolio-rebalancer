# 모바일 포트폴리오 화면

브랜치: codex/mobile-portfolio-layout. 프런트엔드만 변경하며 DB/잔고/성과 계산식은 변경하지 않는다.

## 화면 구성

1. 포트폴리오 현황
2. 계좌 현황 및 한도
3. 목표 비중 설정
4. 리밸런싱 전략
5. 매매 및 입출금 기록
6. 계좌 마스터 관리
7. 분석 및 확인

기존 화면의 내부 ID는 유지하고 신규 계좌 화면만 accounts ID를 추가한다. 기존 화면 간 이동과 안내 문구는 표시 번호에 맞게 바꾼다. 모바일에서는 화면 선택 드롭다운, 데스크톱에서는 탭 메뉴를 사용한다.

계좌 현황은 기존 대시보드 번들의 account_summaries와 동일한 예금 포함/제외 계산을 사용하고 추가 API 요청을 하지 않는다. 포함 여부는 기존 sessionStorage 키를 공유한다. 휴대폰에서는 계좌를 기본 접고 한 계좌씩 펼치며, 총자산·예수금·잔여 연간 납입한도와 경고는 접힌 상태에서도 표시한다. 데스크톱의 상세 계좌 화면은 기본 펼침을 유지한다.

모바일 포트폴리오 현황은 원화 환산 총자산(예수금 포함), 배당 포함 보유자산 손익·수익률, 자산군 비중을 우선 보여준다. 원금·통화별 상세, 종목별 비중, 예수금 구성은 접는다. 종목명·평가금액·수익률을 누르면 기존 수량·평단·배당·환차·비중 정보를 모두 확인할 수 있다. 보유자산 손익 정의와 정렬은 유지한다.

## 기간 성과

그래프는 측정한 컨테이너 너비에 맞춰 일별·월별·연간 모두 선택 기간 전체를 표시한다. 560px 최소 너비와 자동 가로 이동을 제거한다. 500px 미만 차트는 높이 260px, 축 눈금과 날짜/막대 라벨을 줄이고 정확한 선택 값은 상단에 고정해서 보여준다. 기본 일별 범위는 좁은 차트 30일, 그 외 90일이며 사용자가 선택한 범위는 유지한다.

압축한 연결선도 모든 기록 값을 사용하며, 일자를 합치거나 성과를 평균 내지 않는다. 터치 위치에서 실제 날짜/기간에 가장 가까운 기록을 선택한다. 키보드와 이전/다음 기록 선택도 유지한다. 누락/미확정 구간의 선 끊기, 기준일, 적용 환율과 기록 출처는 유지한다. 과거 성과 미확정 등의 경고는 상세를 접어도 확인할 수 있다. 모바일 성과 표는 접어서 기본 그래프 공간을 확보한다.

## 검증

합성 데이터로 메뉴 순서, 계좌 기본 접힘/펼침, 잔고 경고, 기존 요약 값과 상세 보존, 360/390/430px 기기에서 예상되는 그래프 컨테이너 너비 및 90일/12개월 배치를 검사한다. 가로 스크롤 최소 너비가 없는 SVG 출력과 터치 날짜 선택/누락일 연결 금지를 확인한다. 실제 기기의 레이아웃·터치 시각 검증과 정적 렌더링 검증은 구분한다.

Vercel 프런트엔드 배포만 필요하다. 사용자 검토 전에 main 병합·push하지 않는다. 롤백은 기존 프런트엔드 배포를 다시 선택하면 된다.
