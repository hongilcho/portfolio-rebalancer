# CMA 잔고 확인 화면 개선 · 로컬 검토

- 브랜치: `codex/cma-balance-review`, 기준 main `995091b`.
- 운영 DB, 서버, 설정, 증권사 연결 및 주문을 사용하지 않는 프런트엔드 변경.
- 5번 탭 → 기록 입력 → CMA 잔고·이자 확인에서 앱 잔고 / NH 조회 잔고 / 차이를 우선 표시.
- 잔고가 일치하면 추가 정정이 필요 없음을 안내. 확인된 지급 이자는 기존 사용자 확인과 서버 검증을 거쳐 반영.
- 이자 명세가 확인되지 않은 차이는 기존 예수금 차이 정산 화면으로 계좌와 확인 대상 금액을 전달. 현재 MTS 잔고 재확인 → 차이 미리보기 → 기존 정정 저장 API 순서로 처리.
- 확인되지 않은 0원과 출금가능금액은 정정 목표값으로 자동 사용하지 않음. 전액 이체 후 0원 조회에서는 누락 이체 입력이 우선이며 직접 잔고 정정은 보조 항목으로 배치.
- 정정 후 NH 알림·이체 입력으로 복귀. 기존 알림 초안·매매 입력과 확정 전 요청은 보존. 이체 자체는 사용자 확인 후 기존 입력 기능에서 반영하며 자동 실행하지 않음.
- 지급 명세·조회 원본 항목, 누적 이자, 자동 확인 설정, 처리 이력은 펼쳐보기로 이동.
- 기존 이자 반영, 초기 누적 이자 정리, 취소, 확정되지 않은 요청의 동일 요청 재확인 조건은 유지.
- 전액 이체만으로 과거 미반영 차이를 이자로 확정하거나, 과거 평가액·입출금·매매를 자동 복원하지 않음.
